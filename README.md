## 📲 How to Use

1. Download the **APK** and install it on your Android device.  
2. Open **Sonix Hub**.  
3. Browse movies, TV shows, or music.  
4. Tap **Play** to stream content instantly.  
5. Tap **Download** to save content for offline use.  
6. Use search and categories to explore content quickly.
